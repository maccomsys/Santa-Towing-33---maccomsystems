Native custom WordPress theme for Santa Towing & Garage Services Ltd., engineered for full visual fidelity, Elementor Free compatibility, and standard cPanel PHP/MySQL hosting with zero Node.js server requirements.

== Features ==
* Pre-compiled Tailwind CSS v4 design tokens and responsive layout rules
* TopBar + sticky fixed NavBar with translucent homepage scroll transition and 3-tier responsive menus
* 5-column Footer, Emergency Floating Buttons, Breadcrumbs, and Sitemap Directory
* Seamless Elementor Free support (Full-Bleed Canvas, Full-Width Inner, and Blank Canvas templates)
* Built-in single and archive templates for Cars (st_car), Rentals (st_rental), Auto Parts (st_part), and Service Areas (st_service_area)
