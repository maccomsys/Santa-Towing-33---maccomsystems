Standalone WordPress Operations Console, Pro Forma Invoice & Official Receipt Engine, Customer CRM, Inventory Manager, Site Content Customizer, and HTML5 Canvas Image Studio for Santa Towing & Garage Services Ltd.

== Description ==

Santa Towing Business Manager reproduces the complete Santa Towing administrative console directly inside WordPress + PHP + MySQL with zero Elementor dependency, zero iframes, zero embedded React bundles, and zero Node.js server requirements.

Included Modules:
1. Operations Dashboard with live Desktop/Mobile website preview & quick settings
2. Customers CRM with billing ledger drawer & safe-delete protections
3. Unified Inventory Manager (Cars for Sale, Rental Fleet, Auto Parts, Gallery, FAQs, Careers)
4. Pro Forma Invoice Builder with split live A4 editor, customizable fields/sections, tax/discount/shipping/charges, presets, print, and A4 PDF export
5. Official Receipts Manager with linked-invoice auto-fill & transactional balance calculation
6. HTML5 Canvas Image Studio (crop, 7 aspect ratios, lock ratio, rotate, flip, text & logo watermarks, JPEG/PNG/WebP compression, WP Media Library sync)
7. Document Settings (company letterhead, TIN, currency, terms, remittance instructions)
8. Pages & Text Editor (14 page tabs, SEO character counters, Blog CRUD, FAQ CRUD, Corridor customizer)
9. Brand Colors & WCAG 2.1 Contrast Simulator (Administrator / Business Manager capability restricted)
10. Logo & Favicon Manager (Administrator / Business Manager capability restricted)
11. Contact Links & Navigation Menus (WhatsApp deep-link generator & reorderable nav lists)
12. Website Images Manager (31 image slots with mandatory Alt Text validation)
13. Backup, Export & Audit Activity Log (JSON backups, CSV downloads, seed resets)
14. User Profile, WP Password Security & Site Content Backup/Restore

== Installation ==

1. Upload `santa-towing-business-manager.zip` via WordPress Admin -> Plugins -> Add New -> Upload Plugin.
2. Activate the plugin. Roles (`st_manager`, `st_staff`), database tables (`wp_stbm_*`), and starter data will initialize automatically.
3. Open **Santa Manager** from the left WordPress Admin menu.
