Santa Towing Legacy Browser Data Exporter

Safely extract localStorage and IndexedDB business data from the live old React Admin tab (Read-Only).

Schema: santa-legacy-browser-export-v1
Step 1: Open Old App

Visit your live old Santa Towing React site (the domain where you previously edited pages, invoices, or Image Studio).

Step 2: Run Snippet

Press F12 → Console, paste the snippet below, press Enter (or drag the Bookmarklet to your bookmarks bar and click it on that tab).

Step 3: Download JSON

Your browser downloads santa-towing-legacy-export-YYYY-MM-DD.json without altering any existing browser data.

Step 4: Import to WP

Go to WordPress → Santa Manager → Backup & Export → Import Legacy React Export JSON and upload the file.

Extracted Read-Only Keys: santa_towing_custom_content_v1, santa_doc_settings_v1, santa_doc_customers_v1, santa_doc_invoices_v1, santa_doc_receipts_v1, santa_doc_activity_logs_v1, santa_image_studio_db (IndexedDB studio_images), santa_studio_images_fallback_v1.
Security Exclusion: sessionStorage auth tokens (santa_admin_*, santa_owner_edit_mode_active) are never read or exported.
